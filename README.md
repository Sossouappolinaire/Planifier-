# Planning Sossou Constant

1. Installer l'APK (GitHub > Actions > Build APK > Artifacts).
2. Autoriser l'accès à WhatsApp (accessibilité), les alarmes exactes et la batterie.
3. Coller le lien d'invitation du groupe (chat.whatsapp.com/…) puis « Ajouter » : l'appli retrouve le nom exact du groupe sur la page du lien.
4. Cocher dans « Mes groupes » ceux qui reçoivent l'envoi. À l'heure prévue, l'appli ouvre le groupe directement avec son lien, écrit le message et appuie sur Envoyer.
5. Choisir : intervalle régulier (nombre d'envois + minutes) OU heures fixes (+ nombre de jours).
6. Écrire le message (court ou long), puis « Planifier ».

- « Tester maintenant » envoie tout de suite pour vérifier.
- Le téléphone ne doit pas avoir de code/empreinte à l'écran de verrouillage.
- Un groupe ajouté sans lien (ancienne version) est encore envoyé par recherche de son nom ; pour un envoi direct, le ré-ajouter avec son lien.
- Tous les fichiers sont à la racine (sauf .github) ; build.gradle les range à la compilation.

- Section 5 : saisir ton numéro WhatsApp ; après chaque planification, le récapitulatif (groupes trouvés + envois planifiés) est envoyé automatiquement sur ton WhatsApp, sans cliquer sur Envoyer (accessibilité requise).

- Écran : tableau de bord (groupes choisis / envois en attente / prochain envoi), puis panneaux 1 Autorisations (se replie quand tout est prêt) • 2 Groupes • 3 Horaires • 4 Message et envoi • 5 Envois planifiés • 6 Récapitulatif.

- Si WhatsApp et WhatsApp Business sont installés : choisir lequel utiliser dans le panneau « 2. Choisir les groupes » ; chaque WhatsApp a sa propre liste de groupes. Les doubles applications (Dual Messenger, Second Space) ne sont pas gérées.
